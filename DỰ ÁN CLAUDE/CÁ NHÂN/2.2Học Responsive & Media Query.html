📱💻 Responsive & Media Query

Mục tiêu: trang web đẹp trên cả điện thoại lẫn máy tính. Học theo thứ tự từ trên xuống, mỗi phần ngắn thôi.

1. Từ khóa tiếng Anh cần nhớ

TừNghĩa đơn giản
responsiveTrang tự co giãn, đổi bố cục theo màn hình
viewportKhung nhìn: vùng màn hình mà trình duyệt hiển thị trang
breakpointMốc chiều rộng mà tại đó bố cục đổi (vd 600px, 900px)
media queryCâu điều kiện trong CSS: "nếu màn hình rộng ≥ ... thì áp dụng ..."
mobile firstViết CSS cho điện thoại trước, rồi mở rộng dần cho màn lớn

2. Viewport: dòng bắt buộc phải có

Thiếu dòng này, điện thoại sẽ hiển thị trang như màn hình máy tính bị thu nhỏ, chữ bé tí. Đặt trong <head>:

<meta name="viewport" content="width=device-width, initial-scale=1">

3. Media query và mobile first

Viết CSS mặc định cho điện thoại, rồi dùng min-width để bổ sung cho màn lớn:

.menu { display: grid; grid-template-columns: 1fr; gap: 12px; }

@media (min-width: 600px) {
  .menu { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 900px) {
  .menu { grid-template-columns: repeat(3, 1fr); }
}

Mẹo nhớ: mobile first dùng min-width ("từ ... trở lên"). Breakpoint phổ biến: 600px, 900px, 1200px. Đây là mốc gợi ý, quan trọng là kéo trình duyệt thấy chỗ nào xấu thì thêm mốc.

Các đơn vị nên dùng cho responsive: %, rem, vw, max-width. Ảnh: img { max-width: 100%; height: auto; }

5. Bài tập bắt buộc: Landing page quán cà phê

Yêu cầu: có menu, giờ mở cửa, liên hệ, đẹp trên điện thoại, đưa lên GitHub. Tick từng bước (lưu lại trên trình duyệt của bạn):

Khung HTML để bắt đầu (copy rồi tự thêm nội dung và CSS):

<!DOCTYPE html>
<html lang="vi">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Quán Cà Phê ...</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header><h1>Tên quán</h1></header>
  <main>
    <section id="menu"><h2>Menu</h2> ... </section>
    <section id="gio-mo-cua"><h2>Giờ mở cửa</h2> ... </section>
    <section id="lien-he"><h2>Liên hệ</h2> ... </section>
  </main>
  <footer>...</footer>
</body>
</html>

Đưa lên GitHub (cách dễ nhất, không cần dùng lệnh):

1. Vào github.com → New repository → đặt tên: cafe-landing
2. Bấm "uploading an existing file" → kéo thả index.html, style.css
3. Commit changes
4. (Tuỳ chọn) Settings → Pages → Branch: main → Save
   → có link web chạy thật để gửi thầy/cô

Lưu ý: đặt tên file chính là index.html thì GitHub Pages mới tự mở.

7. Cách kiểm tra trang của bạn

Mở trang bằng Chrome → bấm F12 → bấm biểu tượng điện thoại/máy tính bảng (Toggle device toolbar, hoặc Ctrl+Shift+M) → chọn iPhone/Pixel hoặc kéo chiều rộng. Kiểm tra: không bị cuộn ngang, chữ đọc được, nút bấm đủ lớn.
